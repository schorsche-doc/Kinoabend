# Kinoabend

Небольшое приложение для совместного выбора фильма. Все данные сохраняются в локальной базе SQLite.

## Как это работает

1. На этапе «Предложения» выберите дату вечера и добавьте фильмы. Список фильмов отдельный для каждого дня, а участники общие. Для каждого фильма нужно выбрать автора из списка; один участник может предложить один фильм на конкретную дату.
2. На этапе «Розыгрыш» администратор запускает три ролла. Первый даёт владельцу билетика `10 + вес`, второй `7 + вес`, третий `5 + вес` очков. После третьего ролла побеждает участник с максимальной суммой, а фильм выбирается из его предложений.
3. На этапе «Подтверждение» отметьте присутствующих, поставьте каждому оценку от 1 до 10 и подтвердите автора фильма.

Вес рассчитывается так: базовый балл `1` + до `5` баллов за присутствие + до `4` баллов за давность выпадения. В следующем раунде после победы бонус давности равен `0`, затем растёт на один балл за каждый полностью пропущенный раунд. Штрафов нет. После подтверждения участники получают по одному баллу присутствия, максимум пять. Поэтому фильм с первым местом без бонуса может уступить фильму со вторым местом и бонусом, а третий фильм может обойти их при наличии бонуса и регулярного посещения.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`. Файл базы `kinoabend.sqlite3` создаётся автоматически рядом с приложением.
